从下载到评估

  1. 01 · 取代码先看许可证条目列出仓库、许可证、主要语言和构建方式。标为“仓库未声明许可证”或“非标准模板”的代码，使用或再分发前需要先读 LICENSE 或联系作者。
  2. 02 · 取数据对上数据集和字段数据集目录列出各数据集的布局、大小和下载入口，以及哪些论文用过它。
  3. 03 · 运行以仓库文档为准条目里的示例命令摘自各仓库 README，只用来说明调用方式。需要用同一套代码调用多个压缩器时，可以用 LibPressio。
  4. 04 · 评估用同一套口径OpenSDC-Bench ↗ 提供统一的误差界定义、计时方式和质量指标，榜单 ↗ 已包含 SZ3、ZFP、SPERR、PFPL 和 Falcons。单独分析可用 QCAT 或 Z-checker。

核验方式：仓库逐个通过 GitHub 接口确认存在，并核对 README 是否引用对应论文，依据写在各条目里。论文卡片上的“未检索到公开代码”只表示按题名和系统名没有找到，不代表作者没有公开。许可证、语言和最近提交时间取自核查当日的仓库信息。

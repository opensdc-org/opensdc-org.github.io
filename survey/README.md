# OpenSDC · 数据压缩文献整理

收录 HPC、计算机系统与体系结构领域的数据压缩论文，按发表场所整理研究问题、方法、实验结果和来源，并总结相关研究趋势。

- 网站：<https://opensdc-org.github.io/survey/>
- 文献核验截至：2026-11-13；当前记录为 149 篇主清单、15 篇附录。

## 目录

```text
survey/
├── index.html           # 生成的页面
├── assets/
│   ├── styles.css       # 页面样式
│   └── app.js           # 搜索、筛选、跳转和打印
├── data/
│   └── papers.json      # 论文记录
├── content/
│   ├── scope.html       # 时间范围、收录标准与核验说明
│   └── trends.json      # 趋势分析与论文引用
├── scripts/
│   └── build.py         # 页面生成脚本
└── README.md
```

## 生成与预览

需要 Python 3.9 或以上版本，无第三方依赖。在本目录运行：

```sh
python3 scripts/build.py
```

用浏览器打开 `index.html` 即可预览。页面使用相对路径加载样式和脚本，移动时需保留 `assets/` 目录。

## 更新文献

在 `data/papers.json` 中修改论文记录，在 `content/` 中修改收录标准和趋势分析，然后重新生成页面。统计数字、目录和筛选选项由脚本生成，无需手工修改 `index.html`。

提交时一并提交源文件和生成的 `index.html`。站点沿用仓库的 GitHub Pages 配置，从 `main` 分支发布到 `/survey/`。

## 内容约定

- `id` 为稳定的唯一标识，供目录与趋势引用使用。
- `status` 为 `main`（主清单）或 `appendix`（待核验或边缘相关）。
- 记录题名、发表场所、年份、稳定链接、问题、方法、结果、场景、来源及核验限制。
- `select_reason` 用于解释专题补充的相关性；界面中的范围分类由该字段生成。
- 保留最大值/平均值、基线、硬件、误差设置等实验口径；无法核验的数值明确留作待核验。
- 会议年份、在线优先年份、录用记录与正式出版信息分别注明；核验日期按实际文献检索进度更新。

# OpenSDC · 数据压缩文献整理

面向 HPC、计算机系统与体系结构的数据压缩专题文献目录与趋势分析。

- 网站：<https://opensdc-org.github.io/survey/>
- 所属仓库：<https://github.com/opensdc-org/opensdc-org.github.io>
- 仓库内位置：`survey/`，不是独立的 `opensdc-org/survey` 仓库。
- 文献核验截至：2026-11-13；当前记录为 149 篇主清单、15 篇附录。

## 文件与维护入口

```text
survey/
├── index.html           # 生成的静态页面；与 assets 一起发布
├── assets/
│   ├── styles.css       # 全部样式，含现有 OpenSDC 导航样式
│   └── app.js           # 原有搜索、筛选、跳转、展开和打印逻辑
├── data/
│   └── papers.json      # 全部论文记录；修改论文的唯一入口
├── content/
│   ├── scope.html       # 时间范围、收录标准与核验说明
│   └── trends.json      # 10 项趋势、关联论文 ID 与研究问题
├── scripts/
│   └── build.py         # 静态页面生成脚本，Python 标准库，无额外依赖
└── README.md
```

页面框架、固定说明与渲染规则位于 `scripts/build.py`。统计数字、会议导航、年份分布与筛选选项根据论文数据生成。不要同时手工修改 `index.html` 和数据源：重新生成会覆盖 `index.html`。

## 生成与预览

在本目录运行（Python 3.9 或以上）：

```sh
python3 scripts/build.py
```

然后用浏览器打开 `index.html` 即可。为保留直接本地打开的行为，生成脚本把论文数据嵌入页面；浏览器不需要通过 `fetch` 加载 JSON。CSS 和 JavaScript 使用相对路径，复制或移动页面时须一并保留 `assets/`。

也可以在本目录运行 `python3 -m http.server 8000`，然后访问 `http://localhost:8000/`。页面不需要 Node.js、npm、后端或第三方 CDN。

## 与 GitHub Pages 同步

当前源码目录对应现有仓库中的 `survey/` 子目录。审阅本地改动后，把这些文件放入已有仓库的同名目录，按该仓库现有流程提交和发布即可；不要把它们覆盖到站点根目录，也不需要新建仓库或部署工作流。

运行生成脚本后，应同时提交源码变更和生成的 `survey/index.html`。GitHub Pages 可以直接提供已经生成的静态文件，不要求在线运行 Python。

以本目录的源码和生成的 `index.html` 维护在线版本。历史单文件 HTML 与 PDF 快照不参与站点生成，内容以各自的版本日期为准。

## 内容约定

- `id` 为稳定的唯一标识，供目录与趋势引用使用。
- `status` 为 `main` 或 `appendix`；证据层级与主题相关性是独立概念。
- 记录题名、发表场所、年份、稳定链接、问题、方法、结果、场景、来源及核验限制。
- `select_reason` 用于解释专题补充的相关性；界面中的范围分类由该字段生成。
- 保留最大值/平均值、基线、硬件、误差设置等实验口径；无法核验的数值明确留作待核验。
- 会议年份、在线优先年份、录用记录与正式出版信息分别处理。核验日期反映文献覆盖，不会因修改网页措辞自动更新。
